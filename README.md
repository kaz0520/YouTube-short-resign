# ショート視聴レコーダー

YouTubeショートを **無意識に見てしまう行動を記録し、意識的な選択に変える** ための個人用ツールです。
視聴をやめさせるためのものではありません。「本当に見るか」を自分で選ぶきっかけを作ります。

## 機能

- **開始ボタン** … 視聴開始時刻を記録
- **終了ボタン** … 視聴終了時刻を記録し、視聴時間を自動計算
- **終了後アンケート** … 「良かった / 普通 / 後悔した」を記録
- **履歴画面** … 日別の視聴回数・合計視聴時間・後悔率を表示
- **起動時メッセージ** … 「本当に見ますか？ 禁止ではありません。意識して選択してください」

## データの保存とクラウド同期

- 記録はまず **端末内（ブラウザの localStorage）** に保存されるので、オフラインでも動きます。
- オンラインのときは **Supabase** に自動同期され、**スマホとPCなど複数の端末で同じ履歴** を見られます。
- 同期は「合言葉（同期キー）」方式です。初回起動時に推測されにくいランダムな合言葉が自動生成されます。
  - 別の端末で同じ履歴を見たいときは、履歴画面 →「合言葉の設定」で合言葉を確認・コピーし、
    もう一方の端末の同じ画面に貼り付けて「この合言葉で同期する」を押します。
  - **合言葉を知っている人は履歴を見られます。** 他人に教えないでください。
- ログイン（メール／パスワード）は不要な代わりに、合言葉が実質的なパスワードになります。
  合言葉は自動生成の長いランダム文字列なので、そのまま使うことを推奨します。

## 使い方（インストール不要・これがMVP）

`index.html` をダブルクリックしてブラウザで開くだけです。

- 視聴を始めるときに「視聴を開始する」を押す
- 見終わったら「視聴を終了する」を押してアンケートに答える
- 「履歴を見る」で記録を確認できる

> ヒント: ブラウザのブックマークに登録したり、`index.html` のショートカットをデスクトップに置いておくと、
> ワンクリックで起動できて習慣化しやすくなります。
>
> 注意: データはブラウザごと・オリジンごとに保存されます。同じファイルを同じブラウザで開いている限り履歴は残ります。

## デスクトップアプリとして起動する（任意）

独立したウィンドウのデスクトップアプリとして動かしたい場合は、Electron を使います。

```bash
npm install
npm start
```

`index.html` がそのままアプリ画面として表示されます。HTML を編集すればアプリの中身も変わります。

## ファイル構成

```
index.html    アプリ本体（これ単体で動きます）
main.js       Electron 用の起動スクリプト（任意）
package.json  Electron 用の設定（任意）
```
